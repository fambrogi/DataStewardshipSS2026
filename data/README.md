### Data file description

The dataset "Concentrations of major ions in wet precipitation samples in Austria" consists of 2 *csv* files
DOI: https://doi.org/10.48436/b0g4h-rv840

**precipitationdata.csv**: contains precipitation data including chemicals, ph, conductivity
**stationcoordinates.csv**: contains metadata of the observation stations

This is a re-sharing of the original dataset, possible under the respective licensing obligations. 

---

**units.csv**: contains the units describing the physical measurement according to the SI Digital Framework
